Frozen VESSEL_GROUP TEST는 고정된 내부 평가입니다. 완전히 새로운 외부 입력의 정답 라벨 검증과는 다릅니다. 현재 공개본에서 독립 외부 데이터 정확도, 노동시간·비용 절감, 전체 운영 정확도는 측정하지 않았습니다. Random Negative AP는 baseline 진단이며 서비스 전체 정확도로 대체하지 않습니다.

공개 smoke test는 합성 데이터만 사용합니다. 입력 오류, 정규화, exact/fallback 검색, 피처, gate 경계, 검토 정책, V4.2 순위 보정 및 합성 배치 경로를 확인합니다. 테스트의 임시 모델은 배치 연결 확인용 고정 점수 stub이며 제품의 학습 모델이 아닙니다. 원본 데이터 기반 회귀·전체 성능 재현은 포함하지 않습니다.

서비스 판정이 원본과 같다는 근거는 core 및 service 파일의 바이트 동일성입니다. 모델과 비공개 자산을 공개하지 않으므로 공개 저장소 단독으로 실제 예측 parity를 재실행할 수 없다는 한계가 있습니다.
